how a workspace works
A workspace reads straight from your project.
Creating one copies nothing. Every file you open comes from the original.
Writes land in a separate layer.
A file is copied up the first time it changes. New files go there too.
Deletes leave a marker.
The original stays where it is. The workspace stops showing it.
That layer is the diff.
Nothing to scan. What changed is exactly what is in it.
Merge applies it. Drop throws it away.
Your project only changes when you say so.
On macOS forkspace uses APFS clones, elsewhere reflinks or a plain copy, and tracks changes against a manifest. Same commands, same output.
